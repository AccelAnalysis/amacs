# Controlled Units

Numeric AMACS properties and RFx qualifiers use stable unit IDs rather than uncontrolled text. Labels and symbols may be localized; the unit identity remains stable.

Conversion factors are supplied only where conversion is deterministic within the stated unit family. Currency conversion and calendar-dependent month or year conversion are intentionally not implied.

A quantitative site-selection value should also retain its source, source date, verification status, and value snapshot in the consuming application.
