# Governance Profiles

Request family describes what the market interaction is intended to accomplish. Governance profile describes who controls the process, where authoritative submission occurs, what confidentiality modes apply, and which procedural controls are available.

The initial profiles cover informal private business requests, structured private commercial requests, federal-adjacent preparation, state or local public procurement, institutional procurement, external-system preparation, and confidential site selection.

AMACS does not invent governing law. The selected profile configures platform behavior while the issuer, jurisdiction, institution, project representative, or external system retains the authority described in the profile.
