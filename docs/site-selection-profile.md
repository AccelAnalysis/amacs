# Site Selection Profile

AMACS models site selection as a distinct request family and governance profile, not as a generic procurement RFI. The response architecture supports project fit, proposed sites or buildings, workforce, utilities, logistics, permitting and development risk, operating costs, incentives, and an implementation team.

The decision architecture supports elimination gates, weighted location factors, and comparative cost analysis. One community response may contain multiple candidate property objects, and authorized utilities, workforce organizations, property representatives, localities, and EDOs may contribute assigned sections.

Project identity, candidate geography, data rooms, site tours, negotiations, incentives, and final location authority remain subject to the project representative's confidentiality and governance rules.
