# External crosswalks

AMACS is an original standard. This directory is reserved for lawful, version-specific mappings to external systems such as NAICS, NAPCS, PSC, and CPV, and to licensed systems only where Accel Analysis has sufficient rights.

No external crosswalk records are included in AMACS 0.1.0. Before adding a mapping, document:

- external system and exact version;
- source and retrieval date;
- applicable license, attribution, and redistribution conditions;
- mapping method and reviewer;
- exact, narrower, broader, or related relationship; and
- confidence and review date.

A crosswalk supports interoperability. It does not replace AMACS meaning or automatically convert an industry code into a verified organizational capability.
